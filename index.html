Finance Documentary Automation

Finance Documentary Automation is a private workflow project used to assist with research, scripting, narration, visual asset preparation, and assembly of finance documentary videos.

The workflow may connect to Google Drive to store and manage files needed for video production. Access is authorized by the account owner through Google.

This website provides basic information about the project and its data practices. It does not offer a public video-generation service.
